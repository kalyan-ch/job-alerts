Week 0 — Admin, before any studying

Open with these — reward working-engineer skill

  • Stripe — coding round explicitly not LeetCode (simple IAM, blur card numbers from logs, rate limiter). Bug Bash + Integrations are debugging, not algorithms.
  • Ramp — pair-programming screen, own IDE, build a real feature. Silent coding is a negative signal.
  • Plaid — rewards correctness and edge cases over clever algorithms.
  • Cloudflare — one medium DSA or a practical task. Networking/DNS/TLS weigh more than patterns.
  • Palantir — problem decomposition is pseudocode-at-most.

Hold these until coding is warm

  • Databricks — three coding rounds, "LC hard more than medium", concurrency round rated hardest
  • Snowflake — hard LC each with a harder follow-up, plus language-internals probe
  • Airbnb — one hard problem per round
From ~100K interviews: technical ability did not obviously track success — practice count did. Only ~25% of candidates perform consistently interview to interview. Treat the first wave as paid practice.

Coding — 24 hrs, ~2.5 hrs/wk throughout

Runs in parallel with every other block. Don't batch it.

DSA bar is not lower for senior. CoderPad 2026: algorithmic questions in 43% of assessments, flat from 44% in 2025. Senior problems stack patterns rather than testing one.

System design — 18 hrs, weeks 2–6

Phase 1 — the 12 primitives

Phase 2 — classic prompts (6–8)

Phase 3 — defense drill

Per-company flavor

  • Cloudflare — "design it without managed cloud services like S3 or Pub/Sub"
  • Confluent — partitioning, offset tracking, exactly-once. Always name what you trade off; they look for that framing.
  • Datadog — narrower than peers, no "Design Twitter". Used explicitly for leveling.
  • Plaid — webhooks, retry/backoff, flaky bank APIs, idempotency
  • Snowflake — DB internals probed. Reported prompt: design an RPC system.
AI/LLM design is additive, not a replacement. Anthropic's design round asks LLM-serving (batching, queuing, GPU utilization under variable load). Everywhere else classic distsys is still the round you pass or fail on — interviewing.io's design guide has zero LLM content. Skip DDIA cover-to-cover.

Behavioral — 12 hrs, weeks 4–8

Scored axes

  • Scope of impact — one team / multi-team / org-wide
  • Ambiguity tolerance
  • Influence without authority
  • Judgment under tradeoffs, second- and third-order thinking
  • Self-awareness about failure

Company-specific

Technical gets you hired, behavioral sets your level. An ex-Meta hiring committee chair reads behavioral feedback first on staff packets. Down-level cost ~20–30% comp. Plain STAR breaks at staff scope — stories span months and multiple workstreams.

Debug & code review — 6 hrs, weeks 6–7

Grading axis: juniors flag style, seniors flag correctness risk and rank findings by impact. Stripe's Bug Bash rewards methodical hypothesis-testing over barreling in. Palantir plants deliberate red herrings — don't fixate on the first bug. CoderPad 2026: code review 21%, debugging 19% of assessments.
